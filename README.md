# Batalha-da-VM
Site desenvolvido para a Batalha da VM, projeto cultural de batalhas de rima em Ibitinga-SP. O projeto foi criado como atividade de extensão do curso de Ciência da Computação, com foco em divulgação artística, identidade visual e acessibilidade digital.
# Batalha da VM

Projeto desenvolvido como atividade de extensão do curso de Ciência da Computação.

O site foi criado para divulgar a Batalha da VM, apresentando artistas, vídeos, galeria de fotos e informações sobre o projeto cultural.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página responsiva
- Galeria de imagens com modal
- Integração com vídeos do YouTube
- Links para redes sociais
- Navegação simples e intuitiva
